Saya mulai mengenal dunia IT dari kakak yang kuliah di bidang tersebut. Saya
sering melihatnya ngoding, mengerjakan tugas, dan membicarakan hal-hal seputar
komputer. Waktu itu saya belum pernah mencoba programming sendiri, tetapi saya
penasaran dengan apa yang dikerjakannya.

## Belajar Python sebelum kuliah

Setelah mendaftar kuliah lewat jalur SNBP, saya punya waktu luang beberapa bulan
sebelum pengumuman dan awal perkuliahan. Saya mengisinya dengan belajar Python
dari nol melalui course di Dicoding. Itu menjadi pengalaman pertama saya
mencoba programming secara langsung.

## Kenapa saya memilih Informatika

Saat kelas 3 SMA, saya mulai memikirkan jurusan yang ingin diambil. Ada beberapa
pilihan yang sempat saya pertimbangkan. Pengalaman melihat kakak kuliah di
bidang IT memberi saya gambaran awal, tetapi rasa penasaran saya sendiri yang
membuat Informatika terasa cocok.

Saya ingin memahami programming, algoritma, logika, dan AI yang sebelumnya
hanya saya dengar atau lihat dari jauh. Akhirnya, saya memilih S1 Informatika
Universitas Udayana dan diterima melalui SNBP.

## Semester pertama

Semester pertama memperkenalkan banyak konsep baru, termasuk logika matematika
dan dasar programming yang dipelajari secara formal. Saya perlu beradaptasi
dengan cara belajar di perkuliahan sekaligus memahami materi yang belum pernah
saya temui sebelumnya.

Di luar kelas, saya bergabung dengan HIMAIF (Himpunan Mahasiswa Informatika).
Pengalaman di organisasi ini memberi saya ruang untuk mengembangkan soft skill.

## Fokus saat ini

Sekarang saya berada di semester 3. Kegiatan kuliah mulai lebih banyak melibatkan
project dan kolaborasi dalam kelompok. Di luar itu, saya sesekali mengeksplorasi
AI Engineering secara mandiri karena saya tertarik pada bidang itu dan Data
Science.
